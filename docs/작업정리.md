## 작업 흐름

### 1. 첫 버전 — 막대 그래프 위젯
- 대상 기기: Windows, Mac, 아이폰
- 데스크톱: 항상 위에 떠 있는 작은 창, 2분마다 자동 새로고침
- 아이폰: Scriptable 앱으로 홈 화면(작게/중간/크게)과 잠금 화면 위젯 지원
- 사용량은 claude.ai 설정 > 사용량 페이지가 내부적으로 쓰는 주소에서 가져옴 (`sessionKey` 쿠키로 인증)

### 2. 디자인 변경 — 네온 링 게이지
- 막대 대신 애플워치 활동 링 스타일의 그라데이션 링 + 글로우
- 바깥 링 = 현재 세션(5시간), 안쪽 링 = 주간 한도
- 70% 이상 주황, 90% 이상 빨강으로 색 변경
- 링 위 흰 점 = 리셋 주기 중 흐른 시간 → "여유 / 적정 / 빠름" 속도 표시
- 새 데이터가 오면 링이 부드럽게 차오르는 애니메이션
- 더블클릭으로 링만 보이는 미니 모드 전환
- Windows 11 / Mac 둥근 모서리

### 3. 미니 모드 새로고침 버튼
- ↻ 버튼 추가. 미니 모드에서는 마우스를 올리면 나타남
- 불러오는 동안 스피너로 바뀜

### 4. cmd 창 없이 실행
- 파일 확장자를 `.pyw`로 바꾸거나 `pythonw`로 실행하면 콘솔 창이 뜨지 않음
- `shell:startup` 폴더에 바로가기를 넣어 부팅 시 자동 실행

### 5. 버그 수정 — 클릭 시 "응답 없음"
- 원인: 버튼에 마우스가 들어올 때 다시 그리기 → 다시 그리면서 또 "들어옴" 신호 발생 → 무한 반복
- 해결: 마우스 좌표로 버튼 위인지 직접 계산하도록 변경, 상태가 바뀔 때만 다시 그림

### 6. 사용 설명서 작성
- 설명서에 준비, 실행, 자동 실행, 조작법, 화면 읽는 법, 문제 해결, 설정 파일, 삭제 방법 정리

### 7. ChatGPT 사용량 추가
- chatgpt.com/codex/settings/usage 에 나오는 **Codex 5시간 / 주간 한도**를 표시
  - 일반 ChatGPT 채팅 메시지 한도는 OpenAI가 퍼센트로 공개하지 않아 가져올 수 없음
  - 요금제에 따라 5시간 한도가 없으면 주간 링 하나만 표시
- 연결 방법 두 가지
  - Codex에 로그인해 둔 PC면 `~/.codex/auth.json`을 읽어 자동 연결 (읽기만, 수정 안 함)
  - 아니면 chatgpt.com 쿠키 `__Secure-next-auth.session-token` 값 입력
- 화면 구성: 자세히 보기는 Claude / ChatGPT 위아래 칸, 미니 모드는 링 두 개 나란히
- 우클릭 메뉴에서 서비스별 표시 켜기/끄기, 연결 설정 분리
- 한 서비스에서 오류가 나도 다른 서비스는 정상 표시

### 8. 디자인 개편 (v4) — 다이얼 + 카드
- 닫힌 링 대신 아래가 열린 270° 다이얼. 열린 자리에 주기 이름(세션 / 5시간), 미니 모드에서는 서비스 이름 표시
- 서비스마다 둥근 카드로 나누고, 카드 제목 옆에 서비스 색 점(Claude 주황 / ChatGPT 초록), 요금제는 테두리 배지
- 여유 / 적정 / 빠름을 색 글자 대신 알약 모양 배지로 표시
- 평소 색을 정리: Claude 보라·남색, ChatGPT 초록·청록 → 70% 주황, 90% 빨강과 헷갈리지 않게
- 가운데 숫자는 크게, %는 작게. 점·배지·새로고침 버튼은 이미지로 그려 가장자리를 부드럽게
- 글로우는 조금 줄여서 덜 번지게, 창 폭 340 → 360
- 동작(드래그, 더블클릭, 우클릭 메뉴, 설정 파일)은 그대로라 기존 설정을 그대로 이어 씀
- 가짜 데이터로 자세히/미니, 서비스 하나만, 오류 상태 화면을 리눅스(Xvfb)에서 그려 확인

### 9. 디자인 다시 개편 (v5) — 막대 대시보드
- v4도 결국 원형이라 큰 인상이 같다는 의견 → 링·다이얼 구조 자체를 버리고 가로 막대 대시보드로 전환
- 막대는 LED처럼 칸이 나뉜 세그먼트 방식. 사용률만큼 그라데이션으로 채우고, 마지막 칸은 비율만큼만 채움
- 흐른 시간은 흰 점 대신 막대 위 흰 세로선
- 한 줄 구성: 왼쪽 큰 숫자, 오른쪽 막대, 막대 아래에 이름 + 속도 배지 + 초기화 시각
- 큰 숫자는 평소 흰색, 70% 이상 주황, 90% 이상 빨강
- 미니 모드는 정사각형 링 두 개 대신 얇은 가로 띠 (서비스마다 큰 숫자 + 막대 두 개)
- 카드, 배지, 서비스별 색은 v4 그대로
- 창 크기 (서비스 2개 기준): 자세히 보기 340×368, 미니 모드 352×54

### 10. 젤리 캐릭터 (v6) + 투명도 + 맨 앞 고정
- 막대도 밋밋하다는 의견 → 표정 있는 젤리 캐릭터로 전환. 서비스마다 큰 젤리(5시간) + 작은 젤리(주간)
  - 몸속 액체 높이 = 사용률, 몸 오른쪽 ◀ = 흐른 시간, 표정 = 속도
  - 표정: 여유(웃음·볼 빨개짐) / 적정(미소) / 빠름(땀) / 90% 이상(찡그림) / 100%(녹아내림) / 오류(✖ 눈) / 연결 안 됨(감은 눈, 회색)
  - 클릭하면 말랑하게 통통 (부피를 유지하는 눌림·늘어남, 약 2.5Hz·감쇠비 0.3 스프링 — react-spring·anime.js 소스의 수치 참고)
  - 눈동자가 마우스 커서 쪽을 바라보고, 몇 초마다 한 마리씩 눈을 깜빡임
  - 새 값이 오거나 찌르면 그 서비스 젤리만 액체 물결이 잠깐 출렁임 (평소엔 멈춰 있어 CPU를 거의 안 씀)
- 디자인 참고 사이트 조사 (impeccable.style 등): 어두운 글로우·보라→파랑 그라데이션은 흔한 패턴이라 빼고, 서비스마다 한 색 계열 + 2~3단 톤 + 아주 옅은 그레인
- 창 크기 대폭 축소: 자세히 보기 280×254, 미니 모드 216×90
- 투명도: 우클릭 메뉴(100~30%)와 마우스 휠로 조절, 마우스를 올리면 잠시 선명하게 (끌 수 있음)
- 맨 앞 고정 문제: 쓰다 보면 가끔 뒤로 가던 문제 → 2초마다 다시 맨 앞으로 (Windows는 SetWindowPos로 포커스를 뺏지 않고). 메뉴·대화상자가 떠 있는 동안은 잠시 멈춤
- 성능: 젤리 한 마리 그리는 데 약 4ms (윤곽선 필터를 도형 그리기로 바꿔 13.5ms → 3.7ms), 애니메이션은 초당 약 30프레임
- 확인: 크기·눌림·표정 조합 3,976가지 렌더링 오류 없음, 리눅스(Xvfb)에서 모드 전환·투명도·찌르기·맨 앞 고정 동작 확인

### 11. 스플릿 플랩 (v7)
- 젤리는 유치하다는 의견 → 시안 3가지(도트 매트릭스 / 유리 캡슐 / 스플릿 플랩)를 그려 보고 스플릿 플랩으로 결정
- 숫자를 보여 주니 눈금자는 필요 없다는 의견에 따라 숫자 카드만 남김
- 공항 출발 안내판처럼 열 제목(한도 · 사용률 · 속도 · 초기화) + 줄마다 숫자 카드, 속도 글자 카드(여유/적정/빠름), 초기화 시각
- 숫자가 바뀌면 카드가 한 장씩 차례로 넘어감 (34 → 37이면 4, 5, 6, 7). 위쪽 잎이 접히고 아래쪽 잎이 펼쳐지는 2단계 플립
- 불러오는 동안에는 숫자가 무작위로 돌고, 클릭하면 한 번 섞였다가 제자리로
- 미니 모드: 서비스마다 큰 카드(짧은 주기) + 작은 카드(주간), '빠름'일 때만 작은 빨간 램프
- 카드 글자는 Pillow로 그림: Windows는 Bahnschrift(DIN 계열)·맑은 고딕, Mac은 DIN Condensed·Apple SD Gothic Neo, 없으면 Pillow 기본 글꼴
- 투명도·맨 앞 고정은 v6 그대로
- 창 크기: 자세히 보기 300×228, 미니 모드 약 180×66

### 12. 하나만 등록했을 때 + 투명도 설명
- Claude·ChatGPT 중 하나만 등록하면 미니 모드에는 등록한 서비스만 표시
- 자세히 보기에서는 미등록 서비스를 큰 칸 대신 `등록 대기` 글자 카드 한 줄(높이 30)로 → ChatGPT 미등록 시 창 높이 228 → 168
- 등록 여부는 새로고침할 때마다(2분)·연결 설정 대화상자를 닫을 때 다시 확인 → Codex에 새로 로그인하면 자동으로 정상 표시로 바뀜
- 미등록 서비스는 사용량을 불러오지 않음
- README에 투명도 설정 방법(휠·메뉴)과 "마우스를 올리면 선명하게" 때문에 투명도가 안 바뀐 것처럼 보일 수 있다는 안내 추가

### 13. README 등록 방법 자세히
- 설치 단계에서 등록 설명을 떼어 '등록하기' 장으로 따로 정리 (설치 단계는 설치 → 실행 → 자동 실행)
- Claude: 브라우저별(크롬·엣지·웨일 / 파이어폭스 / 사파리) 세션 키 복사 순서, 위젯에 붙여넣기, 성공 확인, 로그아웃하면 만료 등 주의
- ChatGPT: Codex 로그인(설치 → Sign in with ChatGPT → auth.json 위치 → 자동 연결)과 쿠키 복사(.0/.1 합치는 법) 두 방법 비교
- 개발자 도구에서 어디를 눌러야 하는지 번호로 보여 주는 안내도 2장 (실제 화면이 아닌 단순화한 그림, 다른 쿠키 이름은 가림)
- 등록 정보 바꾸기·숨기기·지우기 정리, 보안 주의 (값 = 비밀번호, 내 컴퓨터에만 저장)

## 빠른 시작 (Windows)

```
pip install pillow curl_cffi
```

1. `claude_usage_widget.pyw` 더블클릭
2. Claude 세션 키 입력 (claude.ai 쿠키 `sessionKey`)
3. ChatGPT: Codex 로그인 상태면 자동, 아니면 우클릭 > ChatGPT 연결 설정
4. 부팅 시 자동 실행: `Win+R` → `shell:startup` → 바로가기 넣기

자세한 내용은 [README](../README.md) 참고.

## 설정 파일

- Windows: `C:\Users\사용자이름\.claude_usage_widget.json`
- Mac: `~/.claude_usage_widget.json`
- 세션 키, ChatGPT 토큰, 창 위치, 미니 모드, 항상 위, 서비스별 표시 여부 저장

## 알려진 한계

- 공식 API가 아니라 각 사이트 사용량 페이지의 내부 주소를 쓰는 방식이라, 사이트 구조가 바뀌면 작동이 멈출 수 있음
- 세션 키·토큰은 몇 주 지나면 만료되어 다시 입력해야 함
- 실제 계정으로는 테스트하지 못했고, 가짜 응답 데이터로 화면·동작만 확인함
- 아이폰 위젯은 아직 Claude만 지원하고, iOS 정책상 보통 15분 이상 간격으로만 새로고침됨
- 세션 키·토큰은 로그인 정보와 같으므로 설정 파일을 공유하지 말 것
